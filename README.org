#+TITLE: Org-Roam Dashboard

* Overview
This configuration defines a custom interactive dashboard for Org-roam. It provides a tabular view of your notes, sorted by filename timestamp, with clickable entries that open the corresponding Org-roam node. It displays your notes in a tabular view with columns for Title, Type, Tags, and Backlinks.

* Features
- Interactive dashboard buffer (*Org-roam Dashboard*).
- Clickable Titles: open the Org-roam note immediately on first click.
- Filter by multiple Tags and Types using minibuffer completion.
- Filter buttons for Tags and Types appear at the top of the dashboard buffer.
- Backlinks count shown for each note.

* Usage
1. Load the function into your Emacs configuration.
2. Run ~M-x org-roam-dashboard~.
3. Select (a) tag(s) and type filter (or press =RET= to include all).
4. The dashboard buffer *Org-roam Dashboard* will appear.
5. Click on a note title to open it directly.

* Dashboard Layout
| Title | Type | Tags | Backlinks |

- *Title*: Click to open the note.
- *Type*: Displays the Org-roam node type.
- *Tags*: Displays all tags associated with the note.
- *Backlinks*: Shows the number of backlinks.
