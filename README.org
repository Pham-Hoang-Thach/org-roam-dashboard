#+TITLE: Org-Roam Dashboard

* Overview
This configuration defines a custom interactive dashboard for Org-roam. It provides a tabular view of your notes, sorted by filename timestamp, with clickable entries that open the corresponding Org-roam node. It displays your notes in a tabular view with columns for Title, Type, Tags, Backlinks, Forward Links, and Meta Links.

* Features
- Interactive dashboard buffer (*Org-roam Dashboard*).
- Displays notes in a table with columns: Title, Type, Tags, Backlinks.
- Titles styled with doom-nord palette (blue, no underline).
- Tags truncated with "…" if too long to fit the column.
- Sorting by timestamp in the filename (newest first).
- Tooltip on Title shows the creation date/time parsed from the filename timestamp.
- Clickable Titles: open the Org-roam note immediately on first click.
- Numbers of backlinks, forward links, Meta links are shown for each note.

* Usage
- ~M-x butler/org-roam-dashboard~ → shows dashboard with tag/type filters.
- ~M-x butler/org-roam-untagged-dashboard~ → shows dashboard of notes without tags.

* Dashboard Layout
| Title | Type | Tags | BL | FL | META |

- *Title*: Note title (clickable)
- *Type*: Org-roam node type
- *Tags*: Filtered tags (or all if none selected)
- *BL*: Backlinks count
- *FL*: Forward links count
- *META*: Meta links count
